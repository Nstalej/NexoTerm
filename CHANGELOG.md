# Cambios

## 0.1.0 — 2026-11-12

Primera preview de NexoTerm para Windows x64.

- Ventana persistente, opciones de conexión y terminales por pestaña.
- SSH, Telnet y serial con Plink 0.85; PowerShell local con ConPTY.
- Asistente configurable por usuario: APIs compatibles con OpenAI, Anthropic y Ollama.
- Conversación por sesión, entrada de texto de ancho completo y envío de contexto opcional.
- Clave LLM en memoria o cifrada mediante Windows DPAPI.
- Servidor MCP Streamable HTTP local, autenticado y de solo lectura, generado automáticamente.
- Bitácoras Markdown con filtrado preventivo de credenciales y recuperación del historial.
- Evidencias clasificables; PDF y Markdown del informe con trabajo validado por el operador.
- Instalador y ejecutable portable; automatización de compilación y borrador de release en GitHub.

Esta preview requiere verificar conexiones y comportamiento con equipos físicos. La redacción preventiva no sustituye revisar los informes antes de compartirlos. La clasificación de éxito es una confirmación del operador.
